
# Add Schemas Libraries

> Tools -> Options -> Libraries -> Global 

# Change Top Level Entitiy

> Botão direito no projeto -> Options -> General

- A `top-level-entity` é o arquivo no qual todo projeto se baseia
- Quando um projeto compila, ele compila a `top-level-entity`
- Util para mudar qual formato do circuito sendo testado

# GND / VCC

- GND = 0
- VCC = 1
