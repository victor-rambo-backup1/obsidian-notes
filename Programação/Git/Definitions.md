`Git`: sistema de version control
`Github`: Serviço de hospedagem de repositórios git

`Repository`: Onde todas as versões do seu projeto e seu histório de alterações ficam armazenadas
- Fica dentro da pasta oculta `.git`

`Local Repository`: Repositório no computador local da pessoa 
`Remote Repository`: Repositório nos servidores do Github

`Working Directory`: O folder onde está o projeto, folder normal do sistema operacional
`Stage`: São as alterações que você quer passar para frente
`Commit`: Salva as alterações do `stage` para `repositório local`

`Fork`: Duplicar um repositório remoto para seu perfil pessoal
