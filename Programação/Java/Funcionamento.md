
# JVM

- `JVM` - Java Virtual Machine
- É uma máquina virtual que existe apenas para executar Java
- Permite rodar código em diversos OS e arquiteturas diferentes
- Todo código de java roda em `bytecode`, um código intermediário rodado pelo JVM
- A JVM interpreta o código em java


# JIT

- `JIT` - Just In TIme Compiler
- Ele ve as partes mais executadas pela JVM e enquanto o programa roda compila elas
- Essas partes compiladas são nativamente executadas na CPU real


`.java` -> compilação -> `.class` -> interpretado pela `JIT`
