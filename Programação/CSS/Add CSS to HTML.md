# External Style

> Adicionar estilo para o HTML via um arquivo externo

```html
<link 
  rel="stylesheet" 
  href="caminho" />
```

## Observações
- Forma mais recomendada de adicionar CSS

# Internal Style

> Adiciona o código css diretamente a página atráves do elemento `style`

```css
<style>
/* Código CSS  */
</style>
```

# Inline CSS Style

> Adiciona estilo diretamente ao elemento HTML

### Observações
- Esse método irá subescrever qualquer outro método de aplicar estilo
